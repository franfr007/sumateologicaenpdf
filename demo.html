📖 Generador de PDF - Suma Teológica

Características principales:

  • ✅ Selección de todas las partes de la Suma (Ia, I-II, II-II, III)
  • ✅ Extracción automática desde hjg.com.ar
  • ✅ Generación de PDF con formato profesional
  • ✅ Vista previa del contenido
  • ✅ Diseño responsive
  • ✅ Descarga automática

Cómo usar:

  1. Selecciona la parte (por ejemplo, "Prima Pars")
  2. Ingresa el número de cuestión (por ejemplo, "85")
  3. Haz clic en el botón "Generar PDF"
  4. Espera mientras se descarga y procesa el contenido
  5. El PDF se descargará automáticamente

Tecnología:

La aplicación está construida con:

  • HTML5 - Estructura semántica
  • CSS3 - Diseño elegante y responsive
  • JavaScript Vanilla - Sin dependencias pesadas
  • jsPDF - Generación de PDFs del lado del cliente
  • AllOrigins - Proxy CORS para acceder al contenido

Ejemplo de URL construida:

Para la Prima Pars, Cuestión 85:

https://hjg.com.ar/sumat/a/c85.html

Deploy en GitHub Pages:

  1. Crea un nuevo repositorio en GitHub
  2. Sube los archivos: index.html, styles.css, script.js
  3. Ve a Settings → Pages
  4. Selecciona la rama "main" como source
  5. ¡Tu app estará disponible públicamente!

Estructura del PDF generado:

  • 📘 Portada con información de la parte y cuestión
  • 📝 Título de la cuestión
  • 📖 Prólogo (cuando existe)
  • 📋 Artículos completos con:
    • Título del artículo
    • Objeciones
    • Sed Contra
    • Respondo
    • Respuestas a las objeciones
  • 📄 Numeración de páginas
  • 🔗 Fuente citada

💡 Nota importante:

Esta aplicación no almacena ningún dato. Todo el procesamiento se realiza en el navegador del usuario. Los textos se obtienen directamente desde hjg.com.ar y se procesan localmente para generar el PDF.
