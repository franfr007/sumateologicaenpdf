# 🚀 Inicio Rápido

## ⚡ Empezar en 3 pasos

### 1️⃣ Descargar los archivos
Descarga estos 3 archivos principales:
- `index.html`
- `styles.css`
- `script.js`

### 2️⃣ Abrir en el navegador
Haz doble clic en `index.html` o arrástralo a tu navegador.

### 3️⃣ ¡Usar!
- Selecciona una parte (por ejemplo: "Prima Pars")
- Ingresa el número de cuestión (por ejemplo: "85")
- Haz clic en "Generar PDF"
- ¡Listo! El PDF se descargará automáticamente

---

## 🌐 Desplegar en GitHub Pages

### Opción más rápida (interfaz web):

1. Ve a [GitHub](https://github.com/new)
2. Crea un repositorio público
3. Arrastra los 3 archivos principales
4. Ve a Settings → Pages
5. Activa Pages con la rama "main"
6. ¡Listo! Tu app estará en: `https://TU_USUARIO.github.io/REPO_NAME/`

### Con comandos Git:

```bash
# Iniciar repositorio
git init
git add .
git commit -m "Initial commit"

# Conectar con GitHub
git remote add origin https://github.com/TU_USUARIO/REPO_NAME.git
git branch -M main
git push -u origin main
```

Luego activa GitHub Pages en Settings → Pages.

## ❓ Preguntas frecuentes

**P: ¿Funciona sin internet?**
R: Necesitas internet solo para descargar las cuestiones. Una vez descargadas, los PDFs funcionan offline.

**P: ¿Puedo imprimir los PDFs?**
R: ¡Sí! Los PDFs están optimizados para impresión en A4.

**P: ¿Cuánto tarda en generar un PDF?**
R: Entre 5-10 segundos, dependiendo de tu conexión.

**P: ¿Funciona en el móvil?**
R: Sí, es totalmente responsive.

**P: ¿Hay límite de descargas?**
R: No, puedes generar todos los PDFs que quieras.

## 🆘 Problemas comunes

### "No se pudo cargar la cuestión"
✅ **Solución**: Verifica que el número exista para esa parte.

### El PDF no se descarga
✅ **Solución**: Revisa que tu navegador permita descargas.

### Error de conexión
✅ **Solución**: Verifica tu internet y reintenta.

## 🎨 Personalizar (opcional)

```css

    --primary-color: #8B4513;     /* Tu color favorito */

}
```

### Modificar el título:

Abre `index.html` y cambia:

